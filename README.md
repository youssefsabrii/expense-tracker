# 💰 Expense Tracker

A simple **Expense Tracker Web App** built with **HTML, CSS, and JavaScript**.  
It helps you track your income and expenses with a clean UI and localStorage support.

---

## 🚀 Features

- Add income and expense transactions  
- Automatic balance calculation  
- Local storage persistence (data saved after refresh)  
- Delete transactions  
- Responsive design (works on mobile & desktop)
